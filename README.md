# Repair Pro - ระบบบันทึกและจัดการงานซ่อม

ระบบบริหารจัดการงานซ่อม อะไหล่ บัญชีรายได้ และติดตามประกัน (Repair Management & Warranty Tracking System)

## 🚀 ฟังก์ชันหลัก
1. **แดชบอร์ดสรุปผล (Dashboard)**: สถิติงานซ่อม 4 กราฟวงกลม สรุปยอดรายได้ ต้นทุน กำไร งานใน/นอกประกัน
2. **ตารางงานซ่อม (Repair Jobs)**: ติดตามงานซ่อม อัพเดตสถานะแบบเป็นขั้นเป็นตอนพร้อมแนบรูปภาพ/หลักฐาน
3. **งานซ่อมเสร็จแล้ว (Completed Jobs)**: รายการงานที่ปิดจ๊อบ ส่งมอบแล้ว ตรวจสอบประวัติการซ่อม
4. **รายได้และบัญชี (Financial & Income)**: สรุปรายรับ ค่าอะไหล่ ค่าบริการนอกสถานที่ ค่าส่ง กำไรสุทธิ พร้อมส่งออก Excel
5. **ติดตามประกัน (Warranty Tracking)**: แยกงานในประกัน/นอกประกัน วันหมดอายุ และแจ้งเตือนครบกำหนด
6. **พิมพ์ใบรับซ่อม (Print Ticket)**: ออกใบรับซ่อมพร้อม QR Code สวยงาม พอดีหน้ากระดาษ A4/สลิป
7. **ตั้งค่าร้านค้า (Shop Settings)**: แก้ไขชื่อร้าน เบอร์โทร ที่อยู่ อัตราภาษี รายชื่อช่าง และหมวดหมู่อุปกรณ์

## 🛠 วิธีติดตั้งและรันบนเครื่องของคุณ

### 1. ความต้องการเบื้องต้น
- ติดตั้ง [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป แนะนำ LTS)

### 2. ขั้นตอนการติดตั้ง
```bash
# ติดตั้ง dependencies ทั้งหมด
npm install
```

### 3. เริ่มรันโปรแกรม (Development Mode)
```bash
npm run dev
```
หลังจากรันคำสั่ง ระบบจะเปิดเซิร์ฟเวอร์ที่ `http://localhost:3000` (หรือพอร์ตที่แสดงใน Terminal) สามารถเปิดผ่านเว็บเบราว์เซอร์ได้ทันที

### 4. การ Build สำหรับขึ้นเซิร์ฟเวอร์จริง (Production)
```bash
npm run build
```
ไฟล์ผลลัพธ์จะอยู่ในโฟลเดอร์ `dist/` สามารถนำไปอัปโหลดขึ้น **Vercel**, **Netlify**, **Cloudflare Pages** หรือ Web Server ใดๆ ได้ทันทีแบบฟรี!
